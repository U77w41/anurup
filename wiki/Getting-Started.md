# Getting started

Open https://u77w41.github.io/anurup/ in Chrome, Edge, Firefox or Safari, on a computer or a phone. Nothing needs to be installed and there is no account to create. If you use it often, you can [install it as an app](Install-as-an-App) that also works offline.

## Finding a tool

- The home page lists every tool, grouped into **Photo & Signature** and **PDF tools**.
- Type in the search box to filter, for example `50 KB`, `signature`, `merge` or `password`.
- On a computer the sidebar on the left has the same categories. On a phone, tap the menu button at the top left.

Every tool also has its own address, such as `https://u77w41.github.io/anurup/pdf-compressor/`, so you can bookmark the ones you use most.

## Using a tool

1. Drop a file on the upload box, click it to browse, or paste an image with Ctrl/⌘+V.
2. Change the settings. Each tool explains its options right under them.
3. Click the main button. The result appears below with a preview.
4. Click **Download**, or pick a button under **Continue with this file** to open the result in another tool.

The **How to** steps and **Questions** at the bottom of each tool page cover the common cases.

## Moving a file between tools

Every result has a **Continue with** row. Clicking, say, *Compress image* opens the compressor with the file already loaded. There is no need to download it first. See [Workspace and chaining](Workspace-and-Chaining) for more.

## Dark mode

ANURUP follows your system setting. To switch by hand, click **Dark Mode** at the bottom of the sidebar, or the sun/moon icon on a phone. Your choice is remembered.
