# Workspace and chaining

Most uploads need more than one step. A typical photo goes through crop, background removal and a KB limit. ANURUP lets you do all of that without saving and re-uploading the file between steps.

## Continue with

Every result has a **Continue with this file** row. The first buttons are the usual next steps for that tool. **More tools** lists everything else that accepts the file. Clicking one opens that tool with the file already loaded.

Some common chains:

- Crop → Remove background → Passport photo → Resize to KB
- Signature Cleaner → Resize to KB → Sign & Fill PDF
- JPG to PDF → Compress PDF
- Remove PDF Password → Merge PDF → Compress PDF

## The workspace

Files you pass between tools, or save with **Save to workspace**, go into the workspace. Open it from **Workspace** in the sidebar, or the tray icon on a phone.

- Files stay after you refresh the page. They are stored in this browser only.
- Click a file's thumbnail to preview it. The **⋯** menu has Download, Remove and *Open in* any tool.
- Tick several files and use **Open selected in** to send them together, for example to Merge PDF or JPG to PDF.
- Every upload box also has **Choose from workspace**.
- **Clear all** deletes everything in the workspace.

The workspace keeps up to 60 files. When it is full, the oldest file is dropped.
