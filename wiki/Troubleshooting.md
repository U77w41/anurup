# Troubleshooting

**Background removal is stuck on "Downloading model".**
The first run downloads the AI model, which is tens of megabytes. Wait on a stable connection. After that it is cached and starts quickly.

**A PDF shows "password-protected or restricted".**
Use [Remove PDF Password](https://u77w41.github.io/anurup/pdf-unlock/), or click **Unlock** on the file's *Protected* badge in any PDF tool.

**"Still X KB even at the lowest quality".**
The dimensions are too large for that KB limit. Use smaller dimensions, or check the unit and DPI if you entered cm or inches.

**WebP isn't available, or downloads as JPG.**
Some older Safari versions can't create WebP files. Choose JPG or PNG.

**The browser tab crashes on a very large PDF.**
Everything runs in the tab, so memory is the limit. Split the PDF first with [Split PDF](https://u77w41.github.io/anurup/pdf-splitter/), or use a computer instead of a phone.

**I don't see the latest version after an update.**
Hard-refresh with Ctrl+Shift+R (⌘⇧R on a Mac).

**Something else is broken.**
Open an issue at https://github.com/U77w41/anurup/issues with the tool name, your browser and what you expected to happen. Please don't attach private documents.
